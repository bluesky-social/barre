# barre

A reimplementation of [Yoga](https://github.com/react/yoga), the flexbox layout
engine behind React Native, in Rust. Drop-in through Yoga's C API; aiming to be
more accurate and faster. Built mostly by a swarm of cheap agents under the
[kahvi](https://github.com/mozzius/kahvi) harness.

See [docs/PLAN.md](docs/PLAN.md).
