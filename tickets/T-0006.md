This is a deliberate fix of a Yoga bug, not a port: barre must lay a tree out the same way
whether it is laid out fresh or relaid out after earlier layouts at other sizes. Yoga fails
this (`conformance/divergences.md`), and the tests in the target check it. Yoga's own suite
(everything already passing in `conformance/expected-pass.txt`) must stay green.

Root cause (yoga#2019's analysis, confirmed for #1552 by `conformance/divergences.md`):
`layout.computedFlexBasis` persists across `YGNodeCalculateLayout` calls and is only cleared by
`markDirtyAndPropagate` on that one node. `computeFlexBasisForChild`'s resolved-basis branch only
writes when nothing is stored yet, so a basis computed against a previous layout's container size
(e.g. a percent basis) or by a previous layout's max-content pass is reused. Within a single layout
that retention is load-bearing: the max-content pass stores the content size and the definite pass
keeps it. Clearing the value on clean nodes is wrong (it makes `flex: 1` content collapse to 0).

Direction: treat a stored basis as valid only for the layout (generation) and the constraints
(container main size, owner sizes, direction) that produced it, e.g. by stamping it with those and
checking them in `computeFlexBasisForChild`. When it's stale, recompute it the way the skipped
max-content pass would have (measure the child's content), rather than writing the resolved value.
The generation counter (`computedFlexBasisGeneration`) is already stamped; Yoga only consults it
under `WebFlexBasis`. Make sure the measure/layout cache (T-0004) cannot hand back a result whose
subtree holds stale bases: interaction with the cache is the hard part of #2019.

- Every changed function's doc comment says where and why it deliberately differs from Yoga, with
  the issue numbers.
- Keep per-node persistent state `Copy`, fixed-size and pointer-free (docs/API.md, the RN shim needs it).
- Measure callback counts in Yoga's suite (`YGMeasureCacheTest`, `YGMeasureModeTest`) are part of
  the suite; don't regress them.
