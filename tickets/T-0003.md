Port `display: contents` handling in `yoga/node/LayoutableChildren.h`
(`Iterator::next` / `skipContentsNodes`, with its `backtrack_` stack) into `advance` /
`skip_contents_nodes`. Only nodes with no `display: contents` children work today. The child
counts, contents cloning and cleanup elsewhere are already implemented, so only this file changes.

- The iterator must not allocate in the common case (no contents children): this is a hot loop.
  A small inline stack (e.g. a fixed array with a heap fallback) is fine for the backtrack stack.
- `./spec LayoutableChildren` prints the header; read the whole iterator.
