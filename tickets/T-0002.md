Port `calculateBaseline` from `yoga/algorithm/Baseline.cpp` into `calculate_baseline`.
`is_baseline_layout` is already implemented and `calculate_layout_impl` already calls
`calculate_baseline` where Yoga does, so only this file changes.

- Walk the node's children as Yoga does, through `LayoutableChildren` (docs/API.md), not the
  raw child list.
- A node's baseline function is called through the `LayoutNode` trait (look for how the
  measure function is called in calculate_layout.rs). Yoga's `Event::publish` calls are not ported.
- `resolve_child_alignment` is in `algorithm/align.rs`; don't reimplement it.
