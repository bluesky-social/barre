Two persistence tests show barre cloning children that Yoga leaves shared between an
original tree and its clone (`conformance/tests/YGPersistenceTest.cpp`, ported from Yoga's
own `tests/YGPersistenceTest.cpp`). Find where barre's tree operations differ from Yoga's
(`yoga/YGNode.cpp` and `yoga/node/Node.cpp`) and make them match. Read the failing tests
first and run them with `./conf barre/YGPersistenceTest --show 5`.

- Yoga's persistent model: `YGNodeClone` is shallow (children shared, owner unchanged);
  a node only clones a child when it must write to a child it does not own
  (`cloneChildrenIfNeeded`, during layout, and in some mutation paths in YGNode.cpp).
  Check every path that clones and compare it with Yoga's.
- Don't change layout code; this is about ownership and the child lists.
