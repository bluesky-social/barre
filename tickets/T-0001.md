Port `layoutAbsoluteChild` and its static helpers from `yoga/algorithm/AbsoluteLayout.cpp`
into `crates/barre/src/algorithm/absolute_layout.rs`. The stub already has Yoga's signature, and
`layout_absolute_descendants` (the walk to absolute descendants) is already implemented and calls
it, so only this file changes.

- Read the whole of AbsoluteLayout.cpp with `./spec` before starting; the helpers are short.
- Errata matter here: `AbsolutePositionWithoutInsetsExcludesPadding` and
  `AbsolutePercentAgainstInnerSize` change behaviour. Use the node's `has_errata` the way Yoga
  uses `hasErrata`.
- Reuse the helpers that already exist (`calculate_layout_internal`, bound-axis functions,
  `resolve_child_alignment`, trailing-position helpers, node/style accessors in `NodeExt`);
  grep before writing your own.
- Yoga's `Event::publish` calls are not ported (barre has no event system).
