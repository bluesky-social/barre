Port Yoga's measure/layout cache: `canUseCachedMeasurement` with its three static helpers
(`yoga/algorithm/Cache.cpp`) into `can_use_cached_measurement`, and the cache *lookup* block of
`calculateLayoutInternal` (from `if (node->hasMeasureFunc())` down to the end of the
measurement-cache loop) into `find_cached_result`. `calculate_layout_internal` already calls
`find_cached_result` and already records results exactly as Yoga does; today the lookup always
misses, so measure callbacks are called more often than Yoga calls them. Only this file changes.

- Port it faithfully, including the cache indexing. barre will later deliberately fix Yoga's
  stale-flex-basis bugs (yoga#2019) in a separate ticket; don't attempt that here.
- `YGNodeCanUseCachedMeasurement` in the C ABI already calls `can_use_cached_measurement`.
